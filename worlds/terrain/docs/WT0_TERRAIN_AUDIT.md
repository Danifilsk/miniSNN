# WT0 Terrain Audit

The WT0 audit covers grid validation, deterministic world/tile conversion, finalization, WATER/LAND/ROCK blocking, one-tile rock behavior, canonical materialization, Terrain Hash V1, Kernel hash determinism, O0/O2 output equivalence, and a smoke test with the real WF0 fish brain.

Sanitizer and POSIX gates report PASS, FAIL, or UNAVAILABLE according to the local toolchain.
