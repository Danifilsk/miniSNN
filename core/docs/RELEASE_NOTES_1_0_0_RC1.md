# miniSNN Core 1.0.0-rc.1 release notes

This release candidate consolidates A1-A6, Block B, C1/C1.5/C2/C3/C4/C5/C6/C7,
D1-A, D1-B, automated D1-C gates, and the recorded manual Studio validation.
It includes LIF,
AdEx, Hodgkin-Huxley, STDP, R-STDP, homeostasis, structural mechanisms,
controlled memory experiments, deterministic evolution, AgentIO, encoder,
decoder, Agent Cycle, checkpoints, replay, Core/Studio separation, and local
audit tooling.

The Core is an experimental SNN platform, not a biological brain model, Worlds
runtime, general agent, or final frozen Bridge API. See
[known limitations](KNOWN_LIMITATIONS_1_0_0_RC1.md) and the
[release checklist](RELEASE_CHECKLIST_1_0_RC.md).

D1 is concluded for `miniSNN Core 1.0.0-rc.1`. The Core-Brain Bridge API is
provisionally stable; D2 remains responsible for any definitive v1 freeze after
the first real integration.
