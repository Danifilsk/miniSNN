# Future Worlds Sprite Contract

No renderer or simulation code reads these assets in WT0.

Future visual associations only:

- WATER: terrain/water.png
- LAND: terrain/land.png
- ROCK: objects/rock.png
- creatures: future transparent-background creature sprites

These folders intentionally contain no PNGs or graphical placeholders. Simulation collision is defined by Terrain and Kernel occupancy, never by sprite pixels or filenames.
